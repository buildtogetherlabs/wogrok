# layers/ — production build

## Stack (bottom → top)

1. **background/** — solid colors
2. **base/wogrok_base.png** — immutable Wogrok DNA (full face locked)
3. **clothing/** — simplified outfits on neck/shoulders
4. **mouth/** — props / facial hair / masks
5. **eyes/** — overlays on locked asymmetric eyes
6. **special/** — tattoos, jewelry, objects, effects
7. **headwear/** — hats / horns / halo (no hair)

## Base

| File | Role |
|---|---|
| `base/wogrok_base.png` | Canonical immutable character |
| `base/master_base.png` | Same as wogrok_base |

## Trait folders

Empty until drawn. IDs must match `config/traits.json`.
