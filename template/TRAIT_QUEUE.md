# WOGROK trait queue

**Export:** 1000×1000 PNG RGBA → `layers/{category}/{id}.png`  
**Base (locked):** `layers/base/wogrok_base.png`  
**Rules:** `docs/PRODUCTION.md` · DNA: `docs/BASE_DNA.md`

## How

1. Lock `wogrok_base.png` underneath.
2. Draw **only the trait** (transparent PNG).
3. Respect asymmetric eyes / deadpan mouth / no hair.
4. Export to the path below. Check the box.
