# WOGROK trait design

Source brief captured from collection design session.

## Core distinction

**BASE WOGROK** (immutable DNA) vs **TRAITS** (story layers).

At thumbnail size you recognize him first. Traits explain *which crypto life* you're looking at.

## 4. Clothing

Largest category. Keep drawing extremely simplified.

### Crypto / NFT staples

Black hoodie, zip hoodie, oversized hoodie, crypto hoodie, HODL / WAGMI / NGMI / REKT / Degen hoodies, tracksuit, puffer, bomber, techwear, trading shirt, crypto conference shirt.

### Internet / meme

Gamer shirt, gaming hoodie, esports jersey, meme tee, Hawaiian, tank, dad shirt, wife-beater, bathrobe, pajamas, sweatshirt, varsity, leather jacket.

### Wealth / crypto bro

Business suit, suit + tie, open-collar dress shirt, turtleneck, luxury robe, fur coat, yacht bro, casino tuxedo.

### Degen

Casino shirt, sleeveless gym, dirty undershirt, ramen-stained hoodie, gambling jersey, ALL IN / BULL MARKET / DIAMOND HANDS shirts.

### Archetypes

Astronaut, cowboy, samurai, knight, pirate, construction worker, scientist, doctor, military, prison jumpsuit, cult robe, king robe.
