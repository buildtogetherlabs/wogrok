# Stonkboyz desk — landing page

Based private trading desk. The mint is on **OpenSea**, not this site.

**Live:** https://buildtogetherlabs.github.io/stonkboyz/mint/

```
cd stonkboyz-final/mint
python3 -m http.server 8787
# open http://127.0.0.1:8787
```

- Supply on the page is **2,222**
- Price and mint date stay **TBA** until set in `CFG` in `index.html`
- **Mint on OpenSea** stays disabled until `CFG.opensea` is the drop / collection URL
- Showcase boyz are a 12-image subset in `assets/boyz/`
- `assets/stonkboysforever.mp3` loops from the side radio. MUTE/UNMUTE is on the widget. Browsers may start muted until the first click.
